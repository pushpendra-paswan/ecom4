# Returns Policy

We want you to love what you buy. If something is not right, you can return it within the return window described below. This page explains which products can be returned, how long you have, and how to start a return.

## Return window: how many days you have to return a product

You have **30 days from the delivery date** to return most products. The 30 days start on the day your order was delivered, not the day you placed it.

**Electronics have a shorter window of 15 days from the delivery date.** This includes headphones, earbuds, smartwatches, speakers, phones, lamps and other electronic devices. For example, headphones delivered 20 days ago are outside the 15-day electronics window and can no longer be returned, while a T-shirt delivered 20 days ago can still be returned.

Once the window has passed, we are unable to accept a return. If an electronic product has stopped working after the return window, please see our Warranty Policy instead.

## Which items can be returned

- Only items from orders that have been **delivered** can be returned. If your order is still placed or on its way, please wait until it arrives. You can cancel an order that has not shipped yet (see our Cancellation Policy).
- **Gift cards cannot be returned.**
- **Perishable items cannot be returned**, such as food, flowers and other goods that spoil.
- Items should be **unused and in their original packaging**, with all tags, accessories and manuals included.

## Returns are per item

Returns are handled **per item**, not per order. If your order contains several products, you can return one of them and keep the others. Each item is returned as a whole order line.

You can make **one return request per item**. Once a return has been requested for an item, another return request for the same item cannot be made.

## How to start a return

Starting a return is easy:

1. Open a support ticket and use the chat.
2. Tell us your **order number** (for example ORD-1234) and **which item** you would like to return.
3. Tell us briefly why you are returning it.

We will check that the item is eligible for return and confirm the next steps in the chat. When the return is accepted, your refund is handled as described in our Refund Policy.

## Quick answers

- **How many days do I have to return a product?** 30 days from delivery, or 15 days for electronics.
- **Can I return a gift card?** No, gift cards cannot be returned.
- **Can I return part of an order?** Yes, returns are per item.
- **My order has not arrived yet. Can I return it?** Not yet. Only delivered items can be returned.
